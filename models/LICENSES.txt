3D gun models used by this game (models/*.glb)
==============================================

All files below are unmodified GLB files by Quaternius (https://quaternius.com),
released under CC0 1.0 Universal / Public Domain Dedication
(https://creativecommons.org/publicdomain/zero/1.0/). Attribution is not required;
credit is given in the lobby footer as a courtesy. The game renames the files and,
at runtime only, converts their materials to Lambert, tints a few variants and adds
small primitive add-ons (suppressor, LMG box mag + bipod). None of these models are
derived from VALORANT / Riot Games designs; they are generic real-world style guns.

============================================

All files below are unmodified GLB files by Quaternius (https://quaternius.com), released under
CC0 1.0 Universal / Public Domain Dedication (https://creativecommons.org/publicdomain/zero/1.0/).
Attribution is not required; credit is given in the lobby footer as a courtesy. They were fetched from
the Quaternius Showcase mirror, which keeps each pack's upstream CC0 licence and source page:
  https://github.com/trebeljahr/quaternius-showcase (public/glb/<pack>/<file>.glb, see its LICENSES.md)
At runtime the game only re-centres / scales each model, converts materials to Lambert and draws it
with InstancedMesh as background / wall-base set dressing (no colliders). None are derived from
VALORANT / Riot Games assets; they are generic low-poly props and plants.
