3D gun models used by this game (models/*.glb)
==============================================

All files below are unmodified GLB files by Quaternius (https://quaternius.com),
released under CC0 1.0 Universal / Public Domain Dedication
(https://creativecommons.org/publicdomain/zero/1.0/). Attribution is not required;
credit is given in the lobby footer as a courtesy. The game renames the files and,
at runtime only, converts their materials to Lambert, tints a few variants and adds
small primitive add-ons (suppressor, LMG box mag + bipod). None of these models are
derived from VALORANT / Riot Games designs; they are generic real-world style guns.

3D agent models + animations (models/agent_*.glb)
=================================================

All by Quaternius (https://quaternius.com), released under CC0 1.0 Universal / Public Domain
Dedication (https://creativecommons.org/publicdomain/zero/1.0/). Attribution is not required;
credit is given in the lobby footer as a courtesy. Original, generic humanoid base bodies and
animations; nothing here is derived from VALORANT / Riot Games characters or animations.

Packs:
  Universal Base Characters [Standard]   https://quaternius.com/packs/universalbasecharacters.html
  Universal Animation Library [Standard]  https://quaternius.com/packs/universalanimationlibrary.html
  Universal Animation Library 2 [Standard] https://quaternius.com/packs/universalanimationlibrary2.html
  (each pack's License.txt: "CC0 1.0 Universal (CC0 1.0) Public Domain Dedication ... Models by @Quaternius")

  https://github.com/NafisRayan/Animate-Rigged-Humanoid-No-Blender
  ("Universal Base Characters[Standard]/...", "Universal Animation Library[Standard]/...",
   "Universal Animation Library 2[Standard]/..." folders, License files included)
