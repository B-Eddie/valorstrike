# Knife inspect + weapon skins (branch hark-skins)

Scope: knife inspect, free weapon skins (original lines), Collection + Store pages, online skin sync. No currency,
no payments, no Riot skin art or names. Client-only cosmetics except the server storing / relaying validated skin ids.

## 1. Knife inspect
- Y (or F) inspects the knife now (the key handler excluded `rw === "knife"`). Gate unchanged otherwise: not while
  swinging (`kSwing > 0`), ADS, reloading, equipping, dead, paused or in Surf.
- Length: guns keep 2.2 s; the knife uses the native `FP_Core_Melee_S0_Tactical_Inspect` montage length
  (SequenceLength 3.2167 s, read from the manifest; 3.2 s fallback). `VM.insT` holds the active length; the native
  clip is stretched to it (`vfDuration`), the gun procedural envelope reads it too.
- Native FP rig: the melee set has an Inspect entry (clip present in models/valorant/animations/FP_Melee.glb), so the
  native arms + knife play the authored flip/twirl inspect. Cancel: a swing (kick > 0.3 zeroes `VM.ins`; the swing's
  attack event wins in `xvFPTick`), switching (swapW wrapper) or ADS/reload; a cancelled inspect now drops the native
  rig to idle at once (`F.kind==='inspect' && VM.ins<=0`; before, the clip played out after a gun inspect was cancelled
  by ADS).
- Procedural fallback (native rig missing): `xKnIns()` raises the blade, turns it toward the camera, one full flip about
  the blade axis, a look, and returns; pose reset after.
- Client-only cosmetic: no network message; online-safe.
- Test: work/test_knife_inspect.cjs.

## 2. Skins system (user change 25 Oct 14:58: Valorant's real collection names, own procedural visuals)
- Catalogue: server/src/skins.json, generated by work/build_skins_catalog.py from the public valorant-api.com catalogue
  (names only: collection, per-weapon skin name, which weapons each line covers, variant names, content tier). 16 lines:
  Prime, Prime//2.0, Reaver, Glitchpop, Oni, Elderflame, Ion, Sovereign, RGX 11z Pro, Singularity, Spectrum,
  Champions 2021, Forsaken, Sentinels of Light, Recon, Ruination; 109 weapon skins + Standard for all 19 weapons.
  Bandit / Warden skins skipped (not in the game). Knife: our model is the tactical knife, so every line's knife is
  "<Collection> Knife" (variant names from that line's melee where it has any; e.g. Oni Knife Kumo / Hana / Tsubame).
- Visuals: no Riot texture/model files. One shared shader patch (onBeforeCompile, cache key 'xsk', so no recompiles
  when switching): tint over the model's own shading, a generated object-space pattern per line (shards, gilded
  bands, camo, circuit traces, glowing seams, gradient glow), emissive accents (pulsing for Glitchpop / Elderflame /
  RGX / Singularity / Spectrum / Ruination). Palette per line in build_skins_catalog.py; variant colours by variant
  name (Red, Gold, Kumo, Red Camo ...). Material clones cached per (material, weapon, skin).
- Applied to: native FP weapon scene (XV.fp.ws, arms untouched), fallback viewmodel (VMS + knife model, never KARM),
  TP guns of every rig (each owner's skin: online from 'sks'/'sk', offline Standard; XSK.botSkins=true shows
  deterministic showcase skins on offline bots for QA), floor guns (offline: the player's own drops; online: the
  server copies the dropper's skin into the floor row as element 5), lobby agent-select Vandal, Collection preview.
- Ids: "<collection>" = Base, "<collection>.N" = variant N of that weapon's skin. Validated per weapon on both sides.
- Persistence: localStorage vs.skins {v:2, eq, owned}; tampered / unowned / invalid entries ignored at load.
  Account (profile) persistence NOT done: the Directory has no per-profile prefs endpoint; adding one is a worker +
  storage change I left out (would need deploy). Open.
- Online: 'hi' carries sk (validated map); 'sk' {s} on change (debounced 250 ms); server cleanSkins (src/skins.js)
  rejects the whole payload on any bad id / weapon / shape and answers 'skr'; stores u.skins and relays
  {t:'sk',id,s} to the room; 'sks' (all humans' skins) is sent on welcome and before every 'start'. Bots none.
- Old colour-only "Inventory" swatches retired (they were never persisted); the old modal is kept as "Sprays".
